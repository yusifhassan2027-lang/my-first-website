# الموقع الشخصي - يوسف حسين سقيل

موقع شخصي عصري يعرض السيرة الذاتية، المهارات، الأعمال، ووسائل التواصل.

## التقنيات المستخدمة
- **HTML5** - هيكل الموقع
- **CSS3** - التنسيقات والتصاميم (مع متغيرات CSS وشبكات مرنة)
- **JavaScript** - التفاعلات (تأثير الكتابة، عدادات، نموذج تواصل، ظهور عند التمرير)
- **Font Awesome** - الأيقونات
- **Responsive Design** - متجاوب مع جميع الأجهزة
